# Design Guidelines

## Logo Files
- Primary logo: omega-3-daily-logo.jpeg (1024x768px)
- Favicon: favicon.ico

## Logo Usage
1. Use the primary logo (omega-3-daily-logo.jpeg) for all website headers and branding
2. Use favicon.ico for browser tab icons
3. Maintain consistent padding around the logo (minimum 10px)
4. Do not stretch or distort the logo
5. Maintain version history in filename (e.g., omega-3-daily-logo-v2.jpeg)

## Implementation Rules
1. Always use absolute paths
2. Prefer SVG for crisp rendering
3. Maintain aspect ratio (2:1)
4. Include alt text for accessibility
5. Test in both color schemes

## Maintenance Procedures
1. Update all logo references when adding new variants
2. Keep vector (SVG) and raster (PNG) versions synchronized
3. Verify contrast ratios for different backgrounds
4. Test in both mobile and desktop layouts
5. Maintain version history in filename (e.g., omega-3-daily-logo-v2.png)

## Path Validation Checklist
1. Verify logo paths in all HTML files
2. Confirm dark/light mode image variants exist
3. Check console for 404 errors
4. Test responsive breakpoints
5. Validate cross-browser compatibility
