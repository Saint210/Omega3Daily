# Omega3Daily - Zinzino Balance Test Website

## Project Overview
Omega3Daily is a high-converting, SEO-optimized website for the Zinzino Balance Test, focusing on providing users with an easy way to understand their Omega-3 levels.

## Key Features
- Mobile-first responsive design
- SEO-optimized structure
- Performance-focused implementation
- Clean, modern UI/UX

## Performance Optimization
- Minified CSS and JavaScript
- Lazy loading for images
- Preloaded critical assets
- Semantic HTML5 structure

## SEO Strategies
- Keyword-optimized content
- Schema markup implementation
- Meta tags for social sharing
- Canonical URL configuration

## Development Setup
1. Clone the repository
2. Open `index.html` in a modern browser
3. No additional dependencies required

## Database Setup

1. Ensure Python 3.6+ is installed
2. Double-click `setup_database.bat`
3. A new `omega3.db` file will be created

## Database Schema

- Products table: Stores individual product information
- Pricing table: Contains retail/premier pricing
- Kits table: Manages product bundles
- Subscriptions table: Handles recurring orders
